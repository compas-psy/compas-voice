# КОМПАС — иконка приложения (финал, вариант b)

Точное дерево из родительского логотипа на графитовой базе приложения: тёплое терракотовое свечение сверху + два дыхательных кольца (белое / терракотовое). Все растровые версии сгенерированы из вашего вектора `kompas-tree.svg`.

## Что внутри

### App Store / загрузка
- `AppIcon-1024.png` — **1024×1024**, плоская заливка без прозрачности, без скруглений (iOS скругляет сам). Это то, что грузится в App Store Connect.

### Размеры iOS (@2x/@3x, iPad, Spotlight, Settings)
`AppIcon-180.png` (iPhone @3x) · `AppIcon-120.png` (iPhone @2x) · `AppIcon-167.png` (iPad Pro) · `AppIcon-152.png` (iPad @2x) · `AppIcon-87.png` · `AppIcon-80.png` · `AppIcon-76.png` · `AppIcon-60.png` · `AppIcon-58.png` · `AppIcon-40.png` · `AppIcon-29.png`.

### Tinted / монохром (iOS 18)
- `AppIcon-Tinted-1024.png`, `AppIcon-Tinted-180.png` — белое дерево на прозрачном фоне. iOS 18 сам перекрашивает по системному оттенку в tinted-режиме хоума.

### Готовый ассет-каталог Xcode
- `AppIcon.appiconset/` — папка с `Contents.json` (универсальная 1024 + tinted-слой) и вложенными PNG. Перетащите её в `Assets.xcassets` проекта — Xcode подхватит и сам нарежет остальные размеры из 1024.

### Векторные исходники
- `kompas-icon-source.svg` — **полная иконка вектором** (фон-градиент + свечение + кольца + дерево). Масштабируется без потерь; отсюда рендерить любые нестандартные размеры.
- `kompas-tree.svg` — только знак дерева (белый, прозрачный фон) для внутриэкранного использования, водяных знаков, монохромных нужд.

### Анимация
- `splash.html` — **дышащий сплэш** (self-contained, без внешних файлов): кольца дышат циклом 10 сек (4с расширение / 6с сжатие), уважает `prefers-reduced-motion`. Открыть в браузере как есть. Для нативного приложения — воссоздать в SwiftUI (`withAnimation(.easeInOut(duration:).repeatForever)`) на LaunchScreen/загрузочном экране; статичный LaunchScreen storyboard использует `AppIcon-1024` по центру на фоне `#0E1014`.

## Токены иконки
- Фон: радиальный градиент top-lit `#20242E → #14171F (55%) → #0E1014`.
- Свечение: радиальное `rgba(201,138,107,0.30) → 0`, центр вверху (~16% высоты).
- Кольца: внешнее `rgba(255,255,255,0.10)`, внутреннее `rgba(201,138,107,0.34)`; толщина = размер/100; радиусы 46% и 38.5% от стороны.
- Дерево: `#FDFDFD`, занимает ~56.6% стороны по центру.

## Замечания
- **Не** добавляйте прозрачность или скругления в загружаемую 1024 для App Store.
- Полноразмерный набор PNG приложён на случай ручной сборки; при использовании `AppIcon.appiconset` в современном Xcode достаточно одной 1024 (+ tinted).
- Если понадобится светлая тема иконки под tinted/clear-режимы iOS 18 — скажите, отрендерю дополнительный набор.
