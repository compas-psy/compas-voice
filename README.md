# КОМПАС — голосовые практики (Android)

Мобильное приложение голосовых практик — **навигатор состояний**, а не
библиотека медитаций. Пользователь приходит выйти из конкретного состояния
(не может уснуть / не может выключить работу / тревожно / потерял опору).
Ядро — глубокий мужской голос и точные сценарии переходов. Главный принцип
взаимодействия: **от открытия до звука — не более двух тапов.**

> Это **отдельный продукт**, не связанный с сервисом для психологов
> (`cmpas.ru`). Отдельный репозиторий, отдельная кодовая база, отдельная
> аудитория (B2C, городские люди 25–45).

## Стек

- **Kotlin 2.1 + Jetpack Compose** (Material 3), тёмная тема — единственная в MVP
- **Media3 (ExoPlayer)** — воспроизведение практик, фон, таймер сна
- **DataStore** — локальное хранение (чек-ины, история, настройки) — без бэкенда
- **Navigation-Compose** — навигация
- minSdk 26 (Android 8.0), targetSdk 35

Дизайн — «кастомный» (дышащие радиальные градиенты, кольца плеера, управление
яркостью экрана), без сторонних UI-библиотек. Шрифт — системный (нативный).

## Структура

```
docs/                     # продуктовая/DPO/QA проработка (читать перед работой)
  PRODUCT.md              # CPO: логика всех экранов, флоу, edge-cases, тон
  PRIVACY-DPO.md          # DPO: данные, 152-ФЗ, разрешения, политики сторов
  QA-TESTPLAN.md          # QA: тест-кейсы, a11y, анти-паттерны, DoD
  DESIGN-SYSTEM.md        # маппинг токенов дизайна → Kotlin
  ROADMAP.md              # что сделано / что дальше
design_handoff_kompas_mvp/# ТЗ Claude Design (источник истины по дизайну)
android/                  # Android-проект (Kotlin + Compose)
.github/workflows/        # CI: сборка APK
```

## Сборка

APK собирается автоматически через GitHub Actions при пуше в `main`
(и по `workflow_dispatch`). Скачать — во вкладке Actions/Releases.

Локально:
```
cd android
./gradlew assembleDebug     # или: gradle assembleDebug --no-daemon
```
APK: `android/app/build/outputs/apk/debug/`.

## Статус

Первый заход: полная продуктовая/DPO/QA-проработка + каркас Android-приложения
(дизайн-система, дышащий фон, навигация, локальные данные, ключевые экраны,
Media3-плеер). См. `docs/ROADMAP.md` — что готово и что дальше.

Аудиофайлы практик в дизайн-пакет не входят и поставляются отдельно; до их
появления каталог использует плейсхолдер-метаданные, плеер работает с тестовым
источником.
