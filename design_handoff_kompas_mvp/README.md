# Handoff: КОМПАС — приложение голосовых практик (полное ТЗ MVP)

Это исчерпывающая спецификация для реализации приложения по дизайн-референсам. Разработчик, не участвовавший в проектировании, должен суметь собрать продукт по этому документу. Читать целиком до старта.

---

## 0. Что это за продукт
КОМПАС — iOS-first B2C-приложение голосовых практик. **Не библиотека медитаций, а навигатор состояний**: человек приходит не «помедитировать», а выйти из конкретного состояния (не может уснуть / не может выключить работу / тревожно / потерял опору). Ядро — глубокий мужской голос и точные сценарии переходов между состояниями. Главный сценарий: **от открытия приложения до звука голоса — не более двух тапов.**

Аудитория: обычные городские люди 25–45, уставшие, без опыта медитации и без интереса к эзотерике. Слушают вечером/ночью, лёжа, в темноте, одной рукой. Часть — в моменте тревоги, поэтому интерфейс должен требовать **минимум решений**.

## 1. Платформа, стек, фиделити
- **Рекомендуемая платформа: SwiftUI, iOS 16+.** Следовать Apple HIG по духу: таб-бар, Large Title, нижние шиты (`.sheet` + `.presentationDetents`), системный шрифт **SF Pro** (в HTML-референсе — Inter как замена, в приложении использовать `.font(.system())`), материалы `.ultraThinMaterial` для блюров, spring-переходы, тактильная отдача (`UIImpactFeedbackGenerator`), Dynamic Type, VoiceOver.
- **Fidelity: high.** Цвета, типографика, отступы, скругления и микрокопи заданы точно — воссоздавать пиксель-в-пиксель.
- **Тема:** тёмная — **приоритетная и единственная** в этом MVP. Светлая тема НЕ в скоупе.
- Дизайн-референсы (HTML) — это прототипы вида и поведения, **не продакшн-код**. Воссоздать нативно в целевой среде.

## 2. Границы MVP (критично)
**Исключено из MVP** (тянет отдельный бэкенд / аудиоинженерию):
- Персонализация от специалиста («для вас», назначение практик) — требует B2B-портал и связку аккаунтов. Отдельный продукт.
- Пространственный звук (spatial / head-tracking).
- Множество звуковых сред (дождь/море/нейтральный) — каждая = отдельное продакшн-сведение с голосом.
- «Поделиться динамикой со специалистом».

**Входит в MVP:** каталог из 8–12 озвученных практик; главная, подсказывающая состояния по времени суток (системные часы, без бэкенда); чек-ин 0–10 «было→стало» (локально); таймер сна; сонное угасание; тёмный ночной режим; программный фон плеера; **бинауральный фон** (см. §7).

## 3. Анти-паттерны (жёстко НЕ делать)
Стрики, серии дней, бейджи, уровни, «вы пропустили», конфетти/празднования, рейтинги звёздами, соцфункции, шеринг-провокации, автовоспроизведение следующего трека, тревожные пуши, тёмные паттерны в пейволле (никаких таймеров обратного отсчёта). Микрокопи — **разрешающий тон**: «можно», «если будет удобно», «необязательно сейчас». Никогда — «вы должны», «не сдавайтесь», «вернитесь».

## 7. Бинауральный фон (важный нюанс позиционирования)
Онбординг 2b прямо обещает «без магических частот». Бинауральные биения обычно продают как «частоты для мозга» — это прямое противоречие. Поэтому в продукте бинаурал подаётся как **звуковая среда/атмосфера** (мягкий стерео-фон), НЕ как «лечебные частоты».
- **Где:** третий сегмент в блоке «Фон» шита `1c`; значение в «Фон по умолчанию» профиля `6a`.
- **Копи:** название «Бинауральный»; подпись «Мягкий стереозвук под голосом. Нужны наушники.» НЕ писать «настройка на альфа/тета», «частоты для сна», проценты эффективности.
- **Поведение:** работает только в стерео через наушники; при выводе на встроенный динамик автоматически откатываться на «Мягкий фон» и показывать строку про наушники (определять маршрут через `AVAudioSession.currentRoute`). По умолчанию среда = «Только голос».
- **Техника:** два слегка расстроенных тона на канал (`AVAudioSourceNode` / два осциллятора, разница ≤ ~8 Гц) либо предрендеренные стерео-стемы; микшировать тихо под голосом (голос ведущий, фон ≈ −18…−24 dB). VoiceOver проговаривает и название, и условие про наушники; тач-цель ≥48pt; не автозапускать без явного выбора.

## 8. Движок фона плеера (референс: `player-background/КОМПАС-дыхание.dc.html`)
Полностью **программный** (без видео/GIF/картинок), лёгкий. Один движок, три режима отрисовки, свой оттенок на семейство. В HTML — Canvas 2D + `requestAnimationFrame`; в SwiftUI — `TimelineView(.animation)` + `Canvas` (или слои `CAGradientLayer`/`CAShapeLayer`).

### 8.1 Базовое дыхание (общее для всех режимов)
Функция фазы от времени, **цикл 10 сек, 4с расширение / 6с сжатие** (синхронно с пейсингом трека):
```
tt = time % 10
breath = tt < 4 ? smoothstep(tt/4) : smoothstep(1 - (tt-4)/6)   // 0..1, пик на 4с
smoothstep(x) = x*x*(3 - 2x)
```
`prefers-reduced-motion` → зафиксировать `breath = 0.6` (замереть на среднем вдохе), без анимации.

### 8.2 Реакция на звук
`AudioContext` → `AnalyserNode` на выходном миксе трека (в iOS: `AVAudioEngine` + `installTap(onBus:)` на mainMixerNode, считать RMS буфера). Каждый кадр: средняя громкость `target` (0..1), сглаживание:
```
level += (target - level) * 0.08
```
`level` подмешивается к масштабу/яркости/длине форм. Голос ведущий → реакцию держать мягкой (коэффициенты ниже), чтобы фон дышал с музыкой, а не «прыгал» на согласных.

### 8.3 Режим A — «Дымка» (fog)
3 мягких радиальных пятна на почти-чёрной базе, режим смешивания `lighter` (в SwiftUI — `.blendMode(.plusLighter)`). У каждого пятна — первичный медленный дрейф + вторичный быстрее (колыхание) + независимое покачивание радиуса (амёба):
```
sway = 0.055 + level*0.03
cx = W*(x + sin(t*ds + ph)*sway + sin(t*ds2 + ph*1.7)*sway*0.5)
cy = H*(y + cos(t*ds*0.85 + ph)*sway + cos(t*ds2*1.1 + ph)*sway*0.45)
wob   = 1 + sin(t*ds2*1.4 + ph)*0.06
scale = (0.80 + breath*0.30 + level*react*bReact*0.9) * wob
R     = min(W,H) * baseR * scale
alpha = (0.42 + breath*0.34) * (0.7 + level*react*bReact*1.1)
// радиальный градиент цвет@alpha (0%) → *0.45 (55%) → 0 (100%)
```
Параметры трёх пятен: `x=[.32,.70,.52] y=[.34,.66,.86] baseR=[.72,.66,.52] bReact=[1,.7,.45]`, `ds=(0.10+i*0.05)*drift`, `ds2=(0.23+i*0.07)*drift`, `ph=i*2.1`.

### 8.4 Режим B — «Геометрия» (лёгкие линии, реагируют на звук)
Тонкие контуры на базе, `lighter`. Четыре вида:
- **Кольца (rings):** 7 расходящихся от центра колец, `frac=((t*0.05 + i/7)%1)`, `rad=frac*min*0.66*(0.9+breath*0.12+level*0.3)`, `alpha=(1-frac)*(0.32+level*0.7)*0.6`; центр слегка колышется; + постоянное «дышащее» ядро-кольцо `rad=min*(0.13+breath*0.05+level*0.22)`.
- **Лучи (spokes):** 52 радиальные линии, `rot=t*0.045`, длина `len=min*(0.22+breath*0.1+level*0.42*wob)`, `wob=0.55+0.45*sin(k*0.7+t*1.3)`, alpha низкая, `lineCap round`.
- **Волны (waves):** 6 горизонтальных синус-линий, амплитуда `h*(0.012+level*0.075+breath*0.014)`, огибающая `sin((x/W)*π)` гасит по краям, фаза плывёт с `t`.
- **Грань (edge):** вращающийся треугольный контур (поклон «компасу»), `R=min*(0.24+breath*0.08+level*0.28)`, 3 слоя: `poly(R, t*0.1, .5, 1.8)`, `poly(R*0.6, -t*0.15, .3, 1.3)`, `poly(R*1.45, t*0.06, .12+level*0.32, 1.1)`.

### 8.5 Режим C — «Сочетание» (combo, рекомендуется как основной)
Два слоя в один кадр: сначала «Дымка» (цвет, глубина, дыхание), поверх — «Геометрия» (структура, чёткая реакция на звук). Рекомендованное соответствие семейство → фон (конфигурируемо):
| Семейство | Оттенок | Фон плеера |
|---|---|---|
| Сон | indigo | дымка + кольца (реакция приглушена) |
| Выход из дня | terracotta | дымка + лучи |
| Тревога и перегрузка | teal | дымка (медленный дрейф) или дымка + волны |
| Разговоры и решения | ochre | дымка + лучи (чуть живее) |
| Опора | forest | дымка + грань |

Базовые тона (почти-чёрные с оттенком): Сон `#080A11`, Выход из дня `#100C0E`, Тревога `#080F0D`, Разговоры `#110C09`, Опора `#0A0F0C`. Коэффициент реакции `react` на семейство: Сон 0.28, Выход из дня 0.55, Тревога 0.4, Разговоры 0.7, Опора 0.45. `drift`: Сон 0.85, Выход из дня 1.0, Тревога 0.6, Разговоры 1.25, Опора 0.55.

### 8.6 Легибельность и бережность
Поверх фона — вертикальный виньет-градиент для читаемости текста: `rgba(6,7,10,.55)` (0%) → `.05` (32%) → `.15` (70%) → `.7` (100%). Кэп `devicePixelRatio` до 2; 30 fps достаточно; **ставить на паузу при уходе в фон и на экране паузы плеера**; на ночных/сонных практиках понижать яркость экрана (`UIScreen.main.brightness`, сохранять исходное и восстанавливать при выходе).

## 9. State management (всё локально, без бэкенда в MVP)
- `onboardingCompleted: Bool` — флаг первого запуска.
- `currentTimeOfDay: day|evening|night` — из системных часов; определяет плитки и тему главной.
- `selectedState` — выбранное состояние (онбординг/главная).
- `sessionConfig { duration: 5|12|20, background: voice|soft|binaural }`.
- `checkInBefore / checkInAfter: Int?` (0–10) — локально (UserDefaults/SwiftData). Из них «было→стало» и тенденция в профиле.
- `playerState: playing|paused|nightMode|fadingOut` + позиция трека, sleepTimer.
- `history: [Session]` — { title, family, date, durationMin, before, after }.
- `settings { defaultBackground, remindersEnabled=false, subscriptionStatus }`.
- `hasCompletedFirstPractice: Bool` — триггер пейволла.
Аудиофайлы практик — bundled или простой CDN (в дизайн-пакет не входят).

## 10. Доступность
Тач-цели ≥48pt; управление плеером без точных жестов (тап по всему экрану); полный Dynamic Type и VoiceOver (осмысленные лейблы, в т.ч. про наушники для бинаурала); контраст WCAG AA на самых тёмных экранах; никакой критичной информации только цветом; `prefers-reduced-motion` уважается в фоне плеера.

## 11. Иконка приложения (папка `app-icon/`, полный README внутри)
Знак — дерево из родительского логотипа (`kompas-tree.svg`) на графитовой базе + тёплое терракотовое свечение + дыхательные кольца.
- **App Store:** `AppIcon-1024.png` (плоская, без прозрачности/скруглений).
- **Xcode:** перетащить `AppIcon.appiconset/` в `Assets.xcassets` (универсальная 1024 + tinted-слой iOS 18).
- **Размеры iOS:** `AppIcon-{180,167,152,120,87,80,76,60,58,40,29}.png`.
- **Tinted iOS 18:** `AppIcon-Tinted-{1024,180}.png` (белое дерево на прозрачном).
- **Вектор:** `kompas-icon-source.svg` (полная иконка), `kompas-tree.svg` (знак).
- **Сплэш/загрузка:** `splash.html` — дышащий (цикл 10с, `prefers-reduced-motion`), воссоздать в SwiftUI на LaunchScreen.
- **Внутри интерфейса** знак идёт **плоским белым** (`kompas-tree.svg`) — в онбординге (46pt), шапке главной (38pt), профиле, пустых состояниях, пейволле. Свечение+кольца — только для иконки приложения и сплэша, чтобы не конкурировать с терракотовой кнопкой.

### Android (если понадобится)
Adaptive icon двумя слоями: foreground = `kompas-tree.svg` (в safe-zone 66%), background = solid `#14171F`; Play Store 512×512 — из `kompas-icon-source.svg`. Round-версии `AppIcon-*.png` не использовать (обрежутся системной маской).
