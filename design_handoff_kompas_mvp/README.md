# Handoff: КОМПАС — приложение голосовых практик (MVP)

## Overview
КОМПАС — iOS-first B2C-приложение голосовых практик. Это **не библиотека медитаций, а навигатор состояний**: пользователь приходит не «помедитировать», а выйти из конкретного состояния (не может уснуть / не может выключить работу / тревожно / потерял опору). Ядро продукта — глубокий мужской голос и точные сценарии переходов между состояниями. Главный сценарий: **от открытия приложения до звука голоса — не более двух тапов.**

Аудитория: обычные городские люди 25–45, уставшие, без медитационного опыта и без интереса к эзотерике. Слушают вечером и ночью, лёжа, в темноте, одной рукой. Часть — в моменте тревоги, поэтому интерфейс должен требовать минимум решений.

## About the Design Files
Файлы в этом пакете — **дизайн-референсы, созданные в HTML/CSS** (`КОМПАС.dc.html`). Это прототип, показывающий предполагаемый внешний вид и поведение, **а не продакшн-код для копирования**. Задача — **воссоздать эти экраны в целевой среде** нативно.

**Рекомендуемая платформа: SwiftUI (iOS 16+).** Приложение iOS-first и должно следовать Apple Human Interface Guidelines по духу: нативная навигация (таб-бар, крупные заголовки Large Title, шиты снизу через `.sheet`/`.presentationDetents`), системный шрифт SF Pro, `.ultraThinMaterial` для размытий, spring-анимации, тактильные микровзаимодействия (`UIImpactFeedbackGenerator`), поддержка Dynamic Type и VoiceOver. Если команда предпочитает кросс-платформу (React Native / Flutter) — те же принципы, но нативные паттерны iOS в приоритете.

HTML использует **Inter** как замену SF Pro (у SF нет свободной веб-версии). В нативном iOS **используйте системный San Francisco** (`.font(.system())`), а не Inter.

## Fidelity
**High-fidelity.** Финальные цвета, типографика, отступы, скругления и микрокопи заданы точно. Воссоздавать пиксель-в-пиксель средствами целевого стека. Тёмная тема — приоритетная и единственная в этом MVP (светлая тема НЕ входит в скоуп данного релиза).

## Границы MVP (важно!)
Сознательно **исключено из MVP** (тянет отдельный бэкенд / аудиоинженерию):
- **Персонализация от специалиста** («для вас», назначение практик) — требует B2B-портал и связку аккаунтов. Отдельный продукт.
- **Пространственный звук** — отдельная аудиоинженерия.
- **Множество звуковых сред** (дождь/море/нейтральный) — каждая = отдельное продакшн-сведение с голосом. Сжато до «Только голос / Мягкий фон».
- **«Поделиться динамикой со специалистом»** — та же связка аккаунтов.

**Входит в MVP** (дёшево и ценно): каталог из 8–12 озвученных практик; главная, подсказывающая состояния по времени суток (просто системные часы, без бэкенда); чек-ин 0–10 «было→стало» (считается и хранится **локально**); таймер сна; сонное угасание; тёмный ночной режим.

## Анти-паттерны (жёстко НЕ реализовывать)
Стрики, серии дней, бейджи, уровни, «вы пропустили», конфетти/празднования, рейтинги звёздами, соцфункции и шеринг-провокации, автовоспроизведение следующего трека, тревожные пуши, тёмные паттерны в пейволле (никаких таймеров обратного отсчёта). Весь микрокопи — **разрешающий тон**: «можно», «если будет удобно», «необязательно сейчас». Никогда — «вы должны», «не сдавайтесь», «вернитесь».

### Отступы / скругления / тени
- Экран (safe-area паддинги контента): 26px по горизонтали.
- Скругления: плитки/карточки `22px`; крупные CTA-кнопки и поля выбора `18px`; шит сверху `30px`; чипы/сегменты `11–14px`; пилюли `20px`.
- Тач-цели: **минимум 48pt** (кнопки плеера, плитки, строки списка). Управление плеером — без точных жестов (тап по всему экрану = пауза/плей).
- Тень карточек: мягкая, `0 1px 3px rgba(0,0,0,.3)` на активном сегменте; крупные тени только у шита сверху (`0 -30px 60px rgba(0,0,0,.5)`).
- Материал/блюр: таб-бар и оверлеи — `.ultraThinMaterial` (в HTML `backdrop-filter: blur(24px)` + `rgba(20,23,31,.82)`).
- Контраст WCAG AA даже на самых тёмных экранах; **никакой критичной информации только цветом**.

### Дыхательный фон (ключевая анимация)
Абстрактные мягкие пятна, которые «дышат» **циклом 10 сек**, синхронно со звуковым пейсингом трека: **4 сек мягкое расширение, 6 сек сжатие**. В HTML аппроксимировано keyframes `breathe` (0%→40%→100%, scale .78→1.14→.78, opacity .45→.85→.45, `ease-in-out`). Плюс медленный `drift` (translate, 26–34s) для живости. В SwiftUI: несколько размытых радиальных градиентных кругов, `withAnimation(.easeInOut(duration: 4).repeatForever)` на расширение и отдельная фаза на сжатие, либо `TimelineView` с кастомной кривой 4/6. На плеере 2–3 слоя (terracotta + smoky + green), затемняющий вертикальный градиент поверх для читаемости текста. **Автояркость экрана вниз** на ночных/сонных практиках (`UIScreen.main.brightness` с сохранением и восстановлением исходного значения при выходе).

### Шит перед стартом — `1c`, нижний шит поверх каталога
Нативный bottom sheet (`.presentationDetents`), фон `#1A1E27`, ручка сверху. Содержит:
- Eyebrow группы + название-сцена практики.
- **Длительность** — сегмент-контрол `5 / 12 / 20` (трек `#12151C`, активный сегмент `#2A3040`).
- **Фон** — 2 опции сегментами: «Только голос» / «Мягкий фон» (без нейтральный/дождь/море — вырезано из MVP).
- **Мягкий чек-ин** — слайдер «Насколько сейчас напряжённо?» 0–10 (заливка градиент smoky→terracotta, бабл значения «7»), подписи «0 · спокойно» / «10 · на пределе».
- **Кнопка «Начать» (terracotta)** — единственный акцент на экране.
- Ссылка **«Пропустить чек-ин»** — нейтральная, без чувства вины.

### Плеер (таб-независимый, полноэкранный) — самый важный экран
Почти пустой. Дышащий фон (цикл 10с). Крупная зона пауза/плей по центру. **Тап по всему экрану** = пауза/плей. Кнопки: «−15 сек», «Таймер сна», «Фон». Прогресс — едва заметная тонкая линия (2px) + мелкие тайминги. 4 состояния:
- **Играет** (`1a`, фон `#0E1014`): eyebrow группы, крестик закрытия (40px, `rgba(255,255,255,.08)`), название-сцена (30px), центральная зона с двумя пульсирующими кольцами (`ring` анимация) вокруг стеклянного круга 96px с двумя палочками паузы; подсказка «Нажми в любом месте, чтобы поставить на паузу»; ряд из 3 контролов; прогресс 38%.
- **Пауза** (`4a`): дышащие пятна **остановлены** (`animation-play-state: paused`, ниже opacity); в центре — треугольник плей; подсказка «На паузе · нажми, чтобы продолжить»; ряд контролов приглушён (opacity .85).
- **Ночной режим** (`4b`, фон `#07080B`): яркость экрана вниз; минимум хрома — только eyebrow «Сон», строка «Медленное погружение», центральная зона (одно тонкое кольцо), внизу приглушённый ряд «Таймер сна · 20 мин» + прогресс. Всё на пониженной opacity.
- **Сонное угасание** (`4c`, фон `#050609`): **у сонных практик НЕТ финального экрана**. Интерфейс плавно гаснет вместе со звуком (заголовок opacity .16, зона .07, прогресс .05) — никакого «Поздравляем, вы закончили». Реализация: анимировать opacity всех элементов → 0 к концу трека, затем корректно завершить сессию (восстановить яркость, освободить аудио).

## Interactions & Behavior
- **2 тапа до звука**: плитка на главной → шит перед стартом → «Начать» → плеер. (Можно сократить: тап по плитке открывает шит, где «Начать» стартует аудио.)
- **Плеер**: тап по всему экрану = пауза/плей; «−15 сек» перематывает назад; «Таймер сна» открывает выбор длительности сна; прогресс обновляется по позиции трека.
- **Анимации**: дыхание фона 10с (4с expand / 6с contract), `ease-in-out`, `repeatForever`. Переходы между экранами — нативные iOS spring. Тактильная отдача (лёгкий haptic) на «Начать», выбор состояния, паузу.
- **Автояркость**: при входе в ночную/сонную практику плавно понизить `UIScreen.main.brightness`; при выходе — вернуть исходное значение (сохранить до изменения).
- **Сонное угасание**: к концу трека opacity UI → 0, звук затухает, сессия завершается без финального экрана.
- **Ночная главная / ночной режим плеера** выбираются по системному времени (условно 23:00–05:00).

## State Management
- `currentTimeOfDay` (day/evening/night) — из системных часов, определяет набор плиток и тему главной.
- `selectedState` — выбранное состояние (главная/онбординг).
- `sessionConfig` — { duration: 5|12|20, background: voice|soft }.
- `checkInBefore` / `checkInAfter` (0–10) — **хранить локально** (UserDefaults/SwiftData/CoreData); из них считается «было→стало» и мягкая тенденция в профиле.
- `playerState` — playing / paused / nightMode / fadingOut + позиция трека, таймер сна.
- `history` — локальный список прослушиваний (название, дата, длительность, before→after).
- `settings` — { defaultBackground, remindersEnabled=false, subscriptionStatus }.
- `hasCompletedFirstPractice` — триггер показа пейволла.
- `onboardingCompleted` — флаг первого запуска.
Данные MVP — **локальные, без бэкенда**. Аудиофайлы практик — bundled или из простого CDN.
