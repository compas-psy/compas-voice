# CLAUDE.md — инструкции для агента (КОМПАС · голосовые практики)

## Что это
Отдельный B2C-продукт: мобильное приложение голосовых практик — **навигатор
состояний**, а не библиотека медитаций. Android-first (Kotlin + Jetpack Compose),
тёмная тема. **Не путать** с сервисом для психологов `cmpas.ru` — это другой
продукт, другая аудитория, другой репозиторий.

## Перед началом работы — обязательно прочитай
1. `design_handoff_kompas_mvp/README.md` — ТЗ Claude Design (источник истины по дизайну)
2. `docs/PRODUCT.md` — логика экранов, флоу, edge-cases, тон микрокопи
3. `docs/PRIVACY-DPO.md` — данные, разрешения, 152-ФЗ
4. `docs/QA-TESTPLAN.md` — критерии приёмки, анти-паттерны, DoD
5. `docs/ROADMAP.md` — что сделано и что дальше

## Продуктовые принципы (не нарушать)
- **≤2 тапа до звука.** Всё подчинено этому.
- **Тёмная тема — единственная** в MVP. Акцент действий — **только terracotta** `#C98A6B`.
- **Разрешающий тон** микрокопи: «можно», «если будет удобно», «необязательно
  сейчас». Никогда — «вы должны», «не сдавайтесь», «вернитесь», «вы пропустили».
- **Приватность по умолчанию:** данные локальны, без бэкенда и аккаунтов в MVP.
- **Никаких медицинских/целительских заявлений** (и продукт, и модерация сторов).
- **Анти-паттерны запрещены:** стрики, серии, бейджи, уровни, конфетти, рейтинги
  звёздами, соцфункции, автоплей следующего трека, тревожные пуши, обратный
  отсчёт/тёмные паттерны в пейволле.

## Дизайн (не менять без явного запроса пользователя)
- Палитра/типографика/отступы — из `docs/DESIGN-SYSTEM.md` и хэндоффа.
- Дышащий фон — ключевая анимация (цикл 10с: 4с расширение / 6с сжатие).

## Стек
Kotlin 2.1 · Jetpack Compose (Material 3) · DataStore (локальные данные) ·
Media3/ExoPlayer (звук — на этапе интеграции аудио) · Navigation через простой
стейт-роутер. minSdk 26, targetSdk 35. Без Hilt (service-locator `AppContainer`).

## Сборка и деплой
- CI: `.github/workflows/android-build.yml` собирает debug-APK при пуше в `main`
  и по `workflow_dispatch`, публикует релиз с APK.
- Локально: `cd android && gradle assembleDebug` (или `./gradlew` после генерации
  wrapper в Android Studio).

## Технические правила
- Цвета только из `ui/theme/Color.kt` (без хардкода мимо токенов).
- Тач-цели ≥48dp. Поддержка Dynamic Type (размеры в sp).
- Не ломать существующий флоу; при изменении данных — обновлять `docs/`.
