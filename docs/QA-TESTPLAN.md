# КОМПАС · Голосовые практики — тест-план и критерии приёмки (QA)

> Роль QA: превратить продуктовую логику и дизайн-ТЗ в проверяемые критерии.
> Легенда статусов реализации: `[ ]` не сделано · `[~]` частично · `[x]` готово.
> Разделы: функциональные кейсы, состояния/edge, доступность, анти-паттерны,
> производительность, Definition of Done.

## 1. Ключевые приёмочные критерии (must-pass)

- [ ] **«≤2 тапа до звука»:** плитка на Доме → «Начать» в шите → играет голос.
      Ровно два тапа. (Замер на всех трёх темах Дома.)
- [ ] Тёмная тема — единственная; светлой темы в MVP нет; смена системной темы
      не ломает экраны.
- [ ] Дышащий фон: цикл 10с (≈4с расширение / 6с сжатие), `ease-in-out`,
      бесконечно; на паузе — остановлен.
- [ ] Ни одной «мёртвой» кнопки: каждый `onClick` делает осмысленное действие.
- [ ] Разрешающий тон микрокопи везде; нет запрещённых формулировок (§5).

## 2. Онбординг

- [ ] 2a→2b→2c листается кнопкой «Далее» и свайпом; индикатор точек синхронен.
- [ ] На 2c предвыбрано первое состояние; «Начать» активна всегда.
- [ ] «Начать» сохраняет `selectedState` и `onboardingCompleted=true`, ведёт на Дом.
- [ ] Повторный запуск после онбординга — сразу Дом, онбординг не показывается.
- [ ] Убил приложение на 2b → онбординг с начала (прогресс не сохраняется).
- [ ] Системная «назад»: 2c→2b→2a→сворачивание (без пустого экрана).

## 3. Дом «Сейчас» (день/вечер/ночь)

- [ ] Тема и набор плиток выбираются по системному времени; пересчёт на `onResume`.
- [ ] Границы бакетов: 04:59→ночь, 05:00→день, 17:59→день, 18:00→вечер,
      22:59→вечер, 23:00→ночь (проверка ровных границ).
- [ ] Тап по плитке → шит соответствующей практики; haptic + press-scale.
- [ ] Логотип и eyebrow некликабельны.
- [ ] Ночь: фон темнее (`#0A0C10`), заголовок «Не спится?», 3 плитки столбиком,
      приглушённая terracotta в таб-баре.
- [ ] Плитки ≥48pt, вся площадь кликабельна.

## 4. Каталог «Практики»

- [ ] Группы: Сон / Выход из дня / Тревога и перегрузка / Разговоры и решения /
      Опора; счётчик практик в заголовке группы корректен.
- [ ] Карточка: свой градиент по состоянию + дышащее пятно; чипы длительностей
      информативны (не выбор).
- [ ] Тап по карточке → шит.
- [ ] Поиска нет.
- [ ] Large Title сжимается при скролле (нативно).

## 5. Шит перед стартом

- [ ] Дефолты: длительность 12, фон из настроек, чек-ин не записан без касания.
- [ ] Сегменты «Длительность» и «Фон» переключаются; активный сегмент подсвечен.
- [ ] Слайдер 0–10: заливка smoky→terracotta, бабл значения, подписи концов,
      шаг 1, ручка ≥48pt.
- [ ] «Начать» → плеер + старт аудио (тап №2). Двойной тап не стартует дважды.
- [ ] «Пропустить чек-ин» → `checkInBefore=null`, слайдер скрывается.
- [ ] Свайп вниз/тап по подложке закрывает без старта.
- [ ] Свернуть/вернуть → выбранные значения сохранены.

## 6. Плеер (4 состояния)

- [ ] Тап по любому месту экрана = пауза/плей; контролы не всплывают на паузу.
- [ ] «−15 сек» перематывает назад, не ниже 0; перемотки вперёд нет.
- [ ] «Таймер сна» — выбор длительности; по истечении звук затухает ~20с и стоп,
      экран гаснет; таймер переживает блокировку экрана.
- [ ] «Фон» переключает голос/мягкий фон кроссфейдом, не прерывая голос.
- [ ] Прогресс — линия 2px + тайминги прошло/осталось; тап по прогрессу не перематывает.
- [ ] Пауза: дышащие пятна остановлены, треугольник плей, подсказка «На паузе».
- [ ] Ночной режим (группа «Сон» или ночное время): яркость экрана вниз, минимум
      хрома; яркость восстанавливается при выходе/сворачивании.
- [ ] Сонное угасание: UI → opacity 0 к концу трека, звук затухает, **нет**
      финального экрана; сессия корректно завершена (яркость возвращена, аудио
      освобождено).
- [ ] Крестик: не сонная + >30с → экран «После практики»; <30с → тихо закрыть;
      сонные → всегда тихо в Дом.
- [ ] Аудиофокус: звонок/другой плеер → пауза; наушники выдернули → пауза;
      автовозобновления нет (MVP).
- [ ] Фоновое воспроизведение при заблокированном экране; медиа-уведомление
      минимальное (название/пауза-плей/закрыть).
- [ ] Битый/недоступный трек → мягкий экран «Не получилось включить · Повторить».

## 7. После практики / Пейволл / Профиль

- [ ] «После практики» только для не-сонных и при осмысленном прослушивании.
- [ ] Сравнение «было→стало» только при наличии `checkInBefore`; подпись зависит
      от знака дельты; тон разрешающий при любом исходе.
- [ ] «Готово» пишет `checkInAfter`, ведёт на Дом; автопредложения следующей нет.
- [ ] Пейволл — после первой полностью прослушанной практики, один раз, без
      обратного отсчёта; «Пока не сейчас» заметна; цена честная.
- [ ] Профиль: тенденция показывается только при ≥3 практиках с чек-ином за 14д,
      иначе мягкая заглушка; формулировка адаптивна к знаку.
- [ ] «Недавнее» — человекочитаемые даты; «Напоминания» ВЫКЛ по умолчанию;
      включение запрашивает POST_NOTIFICATIONS; отказ не ломает app.
- [ ] «Очистить мои данные» стирает историю/чек-ины/настройки, онбординг заново.

## 8. Доступность (a11y)

- [ ] Контраст WCAG AA на всех, включая самые тёмные экраны.
- [ ] Никакой критичной информации только цветом (иконка/текст дублируют).
- [ ] TalkBack: все интерактивные элементы озвучены осмысленно; слайдер имеет
      значение и подписи; кнопка плеера — «пауза»/«воспроизвести».
- [ ] Dynamic Type: тексты масштабируются; длинные названия-сцены живут в 2
      строки без обрезки; layout не ломается при крупном шрифте.
- [ ] Тач-цели ≥48dp.
- [ ] Reduce motion (ANIMATOR_DURATION_SCALE=0): дыхание/анимации не мешают,
      функциональность сохраняется.

## 9. Анти-паттерны (должны ОТСУТСТВОВАТЬ)

- [ ] Нет стриков/серий/бейджей/уровней/«вы пропустили».
- [ ] Нет конфетти/празднований/рейтингов звёздами.
- [ ] Нет соцфункций/шеринга-провокаций.
- [ ] Нет автовоспроизведения следующего трека.
- [ ] Нет тревожных пушей.
- [ ] Нет обратного отсчёта/предвыбранных списаний в пейволле.

## 10. Производительность и устойчивость

- [ ] Холодный старт до Дома < ~2с на среднем устройстве.
- [ ] Дышащий фон не жрёт CPU/батарею неадекватно (анимация на композиции, не
      перерисовка тяжёлых слоёв).
- [ ] Ротация экрана / смена конфигурации не роняет состояние (rememberSaveable /
      ViewModel).
- [ ] Нет утечек MediaPlayer/яркости при выходе с плеера (проверить return из
      фон/сворачивание/крестик/системный назад).
- [ ] minSdk 26 совместимость.

## 11. Definition of Done (сводно)

Готово, когда:
- [ ] Все must-pass (§1) выполнены.
- [ ] Функциональные кейсы §2–§7 зелёные.
- [ ] a11y §8 пройден на 3–4 ключевых экранах (Дом/Шит/Плеер/После).
- [ ] Анти-паттерны §9 отсутствуют (визуальный аудит).
- [ ] Проект собирается в CI (`gradle assembleDebug`) без ошибок компиляции.
- [ ] Нет «мёртвых» кнопок.
- [ ] Пиксельная сверка 5–6 экранов с HTML-прототипом (цвета/отступы/скругления).
