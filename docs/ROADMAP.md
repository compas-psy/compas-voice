## Дальше (по приоритету)

### 1. Аудио-слой — статус
**Сделано:** фоновый слой на Media3/ExoPlayer (`audio/BackgroundAudio.kt`):
16 петель + 4 сонных хвоста + 5 бинауральных стемов, нормализованы к −30 LUFS и
с запечённым кроссфейдом в стык (`res/raw`, OGG/FLAC). Пул петель по семьям,
LRU-выбор (round-robin), gapless-луп, фейды (вход 2с / пауза 0.4с / стоп 1.5с),
сонное угасание (fade-out фона синхронно с UI). `soundFamily` проставлен всем
практикам. Бинауральный слой реализован **за флагом `spatialAudio` (OFF)**:
третий плеер, только наушники (route через AudioManager), очень тихо, мягкие
фейды 8–10с. UI: 3-й сегмент «Бинауральный» + строка про наушники и опция в
профиле — тоже за флагом (в MVP не видны).

**Осталось:**
- **Голос** (`voicePlayer`) — ведущий слой; встроить, когда придут голосовые файлы.
  Сейчас фон играет под симулированный таймлайн. Публичный контракт менять не надо.
- **Фоновое/lock-screen воспроизведение** — `MediaSessionService` + foreground
  service media playback + медиа-уведомление; вернуть `FOREGROUND_SERVICE_MEDIA_PLAYBACK`.
  Пока фон играет, пока активен экран плеера.
- **Сонный переход на хвост/дельту** — сейчас угасание = медленный fade текущей
  петли (хвосты `bg_sleeptail_*` и `bin_sleeptail_delta` забандлены и замаплены,
  но кроссфейд на них — следующий шаг).
- **Аудиофокус** (пауза на звонок), route-change подписка для бинаурала.
- **ANCHOR_4** — прислано 3 петли (не 4); anchor крутит LRU по 3, пока нет 4-й.
